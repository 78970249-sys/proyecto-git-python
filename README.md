# Juego de Fútbol en Python

Proyecto desarrollado en Python con interfaz gráfica utilizando Tkinter.

## Descripción

La aplicación simula una tanda de penales entre el usuario y la CPU. El jugador puede elegir la dirección del disparo o la dirección en la que desea lanzarse como arquero.

## Funcionalidades

- Tanda de penales contra la CPU.
- Selección de izquierda, centro o derecha.
- Marcador en tiempo real.
- Control de rondas.
- Animación básica de pelota y arquero.
- Resultado final del partido.

## Tecnologías utilizadas

- Python 3
- Tkinter
- Git
- GitHub
- Visual Studio Code
- WSL Ubuntu
